# Export WordPress

Déposer ici :
- l'export XML (wp-admin → Outils → Exporter → Tout le contenu)
- et/ou l'archive du dossier `wp-content/uploads` récupérée chez l'hébergeur

Note : les textes et les 23 témoignages sont DÉJÀ archivés dans `contenu-site-actuel/`.
L'export sert de filet de sécurité et surtout à récupérer les FICHIERS IMAGES,
que l'export XML ne contient pas (il ne contient que leurs adresses).
